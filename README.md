
# BIT Lalpur - Machine Learning Class Notes & Assignments (2026)

Welcome to the official repository for the Machine Learning course at Birla Institute of Technology (BIT), Lalpur Campus. This repository serves as a centralized hub for all lecture notes, practical lab files, and academic assignments.

## 📌 Repository Contents
* **Class Notes:** Conceptual breakdowns, mathematical proofs, and lecture summaries.
* **Assignments:** Problem statements, datasets, and solved code assignments.
* **Lab Work:** Python scripts and Jupyter Notebooks implementing ML algorithms from scratch and using libraries (Scikit-Learn, NumPy, Pandas).

## 🚀 Topics Covered
* Supervised Learning (Regression, Classification, SVM, Decision Trees)
* Unsupervised Learning (Clustering, PCA)
* Model Evaluation & Tuning (Cross-Validation, Hyperparameter Optimization)
* Introduction to Deep Learning

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** NumPy, Pandas, polars, opendatasets, datasets, Matplotlib, seaborn, Scikit-Learn
